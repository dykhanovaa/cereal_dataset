# Cereal Rating Prediction

_**Проект по анализу данных и построению моделей машинного обучения для предсказания рейтинга хлопьев на основе их пищевых характеристик.**_

**Что сделано** 

* Проведён первичный анализ и очистка данных.
* Исследованы числовые и категориальные признаки.
* Выполнен анализ корреляций между признаками и целевой переменной.
* Проведено разделение данных на обучающую и тестовую выборки.
* Выполнено кодирование категориальных признаков.
* Обучены и сравнены несколько моделей регрессии.
* Для Decision Tree выполнен подбор гиперпараметров с помощью GridSearchCV.
* Оценено качество моделей с использованием RMSE и R².

**Стек**

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

**Результаты** 

Linear Regression практически идеально предсказывает rating. RMSE на обучающей выборке составляет 2.53 × 10⁻⁷, на тестовой — 3.59 × 10⁻⁷.

Такой результат указывает на сильную линейную зависимость rating от представленных характеристик.

**Файлы**

* main.ipynb — основной Jupyter Notebook с анализом и моделированием.
* cereal.csv — исходный датасет.
